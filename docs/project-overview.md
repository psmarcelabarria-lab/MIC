# Project overview / Presentación del proyecto

MIC is a conceptual framework under operationalization. This repository is a space to document potential technical implementations and learning resources, not a publication of the full framework or assessment instrument.

**Audience:** Researchers, developers, educators, and psychology professionals interested in responsible AI integration.

**Potential outputs (not yet implemented):** educational prototypes, structured reflection workflows, reusable UI components, and technical documentation.

**Out of scope at this stage:** automated diagnosis, clinical recommendations, patient profiling, clinical risk scoring, and claims of psychometric validity.

---

El MIC es un marco conceptual en proceso de operacionalización. Este repositorio documenta posibles implementaciones tecnológicas y recursos educativos; no publica el modelo completo ni el instrumento de evaluación.

**Destinatarios:** investigadores, desarrolladores, docentes y profesionales de psicología interesados en la integración responsable de IA.

**Resultados posibles (todavía no implementados):** prototipos educativos, flujos de reflexión estructurada, componentes de interfaz reutilizables y documentación técnica.

**Fuera de alcance por ahora:** diagnóstico automatizado, recomendaciones clínicas, perfilamiento de pacientes, puntuaciones de riesgo clínico y afirmaciones de validez psicométrica.
