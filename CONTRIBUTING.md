# Contributing / Contribuciones

Thank you for your interest. MIC is currently an early-stage research and development project. Before proposing code, please open an issue describing the idea and its intended use. Contributions should focus on general-purpose, nonclinical, non-sensitive technical components.

Do not submit real patient data, identifiable case material, confidential records, proprietary assessment items, copyrighted third-party content without permission, or secrets/API keys. Use synthetic examples only.

Submitting an idea or pull request does not mean it will be accepted. The repository does not currently grant a reuse license; contributors should request clarification about licensing before submitting substantial code.
