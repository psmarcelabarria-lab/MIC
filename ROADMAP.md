# MIC · Development roadmap / Hoja de ruta

> Planned work only. No milestone below should be interpreted as a completed feature or a validation claim.

## Phase 0 — Scope and safeguards / Alcance y resguardos
- [ ] Define intended users and permitted use cases.
- [ ] Separate public technical documentation from protected MIC instrument content.
- [ ] Document privacy, security, and clinical-use exclusions.

## Phase 1 — Requirements / Requisitos
- [ ] Map conceptual domains to functional requirements without publishing protected items.
- [ ] Specify accessibility and usability criteria.
- [ ] Define a synthetic-data-only prototyping policy.

## Phase 2 — Prototypes / Prototipos
- [ ] Build an interactive educational demonstration.
- [ ] Test navigation, usability, and accessibility with nonclinical examples.
- [ ] Document known limitations and failure modes.

## Phase 3 — Evaluation / Evaluación
- [ ] Plan expert review and iterative usability testing.
- [ ] Determine whether psychometric validation is appropriate and, if so, design a separate rigorous validation protocol.
- [ ] Review ethical, legal, and data-protection requirements before any real-world deployment.

## Phase 4 — Open components / Componentes abiertos
- [ ] Identify reusable, non-sensitive code components.
- [ ] Choose and apply explicit licenses to released components.
- [ ] Publish documentation, tests, and contribution guidance.
